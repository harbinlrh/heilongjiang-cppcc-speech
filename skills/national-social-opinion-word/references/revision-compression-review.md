# 原意保留、精简重组与编辑核查

适用于精简、限项、版本比较和编辑自评，服从主技能及[个人全国稿规范](personal-model-profile.md)。2026年10月语音修订要求删除默认摘要和出处展示，直接写现实并进一步压缩。需要原意保留的示例时可读[版本比较案例](revision-case-safety-auxiliary.md)，案例中的旧结构和数字不覆盖当前要求。

## 1. 锁定修改对象和比较基准

- 读取实际文档，记录路径、题名、署名和版本角色，不仅凭文件名、版本号或此前声称的字数判断。
- 最新确认稿为编辑基准，早期稿可作回溯基准；用户已完成的修改与本次修改分别说明，不重复认领。
- 比较保留、删除、合并、补足和待核内容。换词不等于增加实质论证，删除原有摘要也不等于正文已完成精简。
- 原件保留，独立输出。比较或技能维护本身不授权改文稿、发邮件或上传文章；用户明确要求更新技能时，只提交相应规则。

## 2. 列出必须保留的实质内容

锁定政策对象、用户原有主张、主要制度工具、责任主体、关键事实、适用条件、资金来源和必要救济。题名依当次要求调整，不借精简更换主题或立场。

逐项记录原段落去向及理由。必要例外、权限、费用责任、个人信息边界和申诉程序保留；事实错误经核验后修正，重大变化简要说明。原意保留不等于延续错误数据。

## 3. 先删除旁枝，再重组句子

精简幅度服从当次要求和有效内容，不强制所有稿件缩短20%至30%。用户仅要求更精炼时，实际删除能去掉的冗余，计算完成比例；内容已经紧凑时不为凑比例删去必要条件。

1. 删除摘要、内容提要、关键词和默认引用展示；仅将摘要中的独有实质信息并入对应正文，不把摘要换名或整段搬到开头。
2. 删除历史数字传播过程、来源考证、常识性长解释、同义复述和口号。使用最新适用数据直接说明现实，保留年份、对象和单位。
3. 按同一问题或办理环节合并段落，不按相邻位置机械拼接。各项先说具体动作，再交代决定可执行性的必要条件。
4. 问题通常三至五项、措施四至六项，依内容拆合，不强制数量或一一对应；短稿可以将问题融入措施。避免把多条不相关主线塞进超长段落制造精简。
5. 减少否定铺垫、反问和套式对照，能正面表达的直接写处理办法。保留法定限制和例外，不把减少否定误作取消责任边界。
6. 检查残句、歧义和指代，保持自然长短句及连续段落。补内容仅限原稿缺少的必要事实、主体、程序、成本和条件，不以增加背景证明专业性。

## 4. 字数及事实边界

- 压缩比例为`（原稿计数字数－修订稿同口径字数）/原稿计数字数×100%`。可报告汉字数或非空白字符数，但两版必须同范围、同方法，并说明是否含题名和署名。
- 原稿含摘要时，计算总压缩幅度可将其计入基准，明确口径；新版默认无摘要。数字、标点和空白是否计入须一致，不混用汉字数与可见字符数。
- 正文含表格、文本框、脚注或修订时检查实际内容及接受状态，不能只提取普通段落即声称已读取全文。修改说明、自评表和证据记录单独统计。
- 多个比较基准分别计算。缩字号、改行距、删署名或减少页数不算正文精简。
- 新增或改变法律、数字和案例结论时核验一手来源；旧稿保留事实未经核验的，不称已验证。新发布日期与统计期分别确认，群体均值不改成人数门槛。
- 金额、比例、期限等拟议参数仍明确为测算或拟议安排。材料不足时收窄或说明，不借删引用把缺证主张变成事实。

## 5. 五项编辑核查

默认记录具体缺陷并修正，不自动给分；用户明确要求评分时仅评编辑完成质量，不评价或排名政治、政策选择，不将评分当作事实核验或报送认可。

| 核查项 | 检查内容 |
| --- | --- |
| 原意及实质措施 | 核心主张去向清楚，主题、主体、条件、例外和责任保留，事实纠错有依据 |
| 精简及信息密度 | 摘要、出处展示、重复铺垫已处理，正文实际压缩，必要内容完整 |
| 结构及逻辑 | 编号正确，按同一问题重组，事实与推理分开，无多主题塞段 |
| 实施条件及证据 | 办理主体、权限、成本、保障清楚，现行规则与拟议参数区分，未决缺口如实说明 |
| 语言及阅读 | 直接进入内容，少用来源引导和套式对照，无残句歧义，长短句自然 |

若进行自评，先留缺陷及定位，再修订，避免事后编造评分过程。事实失实、核心主张丢失、必要条件遗漏、文档缺字或截断，均须修正，编辑分数不替代这些验收。

## 6. 成果交付

交付可编辑Word、同口径字数及实际压缩幅度，简要说明主要变化和未决事项。正式正文不附修改说明、评分、检索过程或证据台账，用户明确要求时另行交付。

按文档技能检查最终全部页面，字体替代如实说明。仅更新技能时不额外生成文章或发邮件；修订稿发送遵循本次及仍有效的明确授权。避免在交付回复中重新展开被删掉的摘要和来源考证。
