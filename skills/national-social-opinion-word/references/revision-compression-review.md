# 原意保留、机制重组与五项自评

适用于精简、限项、版本比较和评分修订，不取代新稿规范。用户当次要求优先，结构按2026-11-07主技能更新：首段事实先行、最后一句提出建议，默认无摘要，问题段数与段长自然变化，建议三至四条。此方法来自2026年9月大型活动安全辅助岗位稿的三版本比较；需要例子时读 [版本比较案例](revision-case-safety-auxiliary.md)，历史项数和段式不作为新稿要求。

## 1. 先确定改哪篇、和哪篇比

- 读取实际文档，不根据文件名、版本号或此前助手声称的字数判断内容。记录路径、正文题目、署名和版本角色；同名v3可能内容不同。
- 有早期稿、用户修改稿和完成稿时分阶段比较。用户已完成的收题、删例、改结构不得归为本轮成果。最新确认稿为编辑基准，早期稿作回溯基准。
- 比较说明区分用户已改、此次删减、此次合并、此次补足、仍待核。只替换词语不能声称增加制度论证。
- 保留原件，独立输出。仅比较或更新技能不自动改Word、发邮件或同步GitHub。

## 2. 建立不能丢的内容清单

锁定政策对象、核心工具、责任主体、关键证据、适用范围、执行动作、保障与救济。题目可收窄，但不能借精简改变立场或取消重要制度安排；用户定题优先。

标记原段落去向：保留、合并位置、删除及理由、实质补充。合并前提炼独立主张，合并后逐条找回；必要例外、权限限制、劳动保护、个人信息边界、申诉程序按原义保留。区分主张保留与法律纠偏，既不以意思不变为由保留错误，也不隐瞒实质改动。

## 3. 先重组，再压缩句子

用户仅说精简但未定幅度时，可按20%—30%为目标并说明；明确篇幅优先。问题按独立机制和证据组织，不预设项数；对策整理为三至四条，具体条数按独立工具确定。保留通俗概念解释、关键数据和真实问题实例，压缩重复铺垫与冗长措施，不削弱推理。

1. 先删同一事实的二次介绍、重复背景、口号及无助理解的比喻。默认不设摘要；用户明确保留摘要时，正文避免照抄摘要。
2. 按共同原因或制度环节合并，不按相邻位置拼接。例如技能报酬与短期用工共同解释训练投入不足；培训记录与设备变化共同解释现场能力问题。
3. 每项建议保留一个主要动作，再安排必要执行、保障和纠错；把适配、归责、评估归入对应措施，不在末尾重复追加。
4. 检查实质项数。不能把互不相干措施藏进几个超长段落，不得重复编号或混用层级制造达标假象。独立工具需要第四条时可单列，仍保持聚焦。
5. 一项问题可一、二或三段，不同小节段数自然有差异；不统一成一段或两段，也不固化为1—2—3。各段字数、句数和展开次序自然变化，长段按中心意思拆开。删套话不删推理，不把正文压成提纲；删句后检查残句、指代和因果。
6. 加厚只增加缺失的责任、程序、成本、边界、例外和验证方式；增加有效制度内容时同步清理重复铺垫，不靠拉长篇幅表达深度。
7. 检查首段：事实、概念、矛盾在前，总体建议只在最后一句。不得把建议移到开头以节省篇幅。

## 4. 字数计算和事实边界

- 比例公式：`(基准字符数－完成字符数) / 基准字符数 × 100%`。默认统计标题、署名、各级题目和正文的非空白可见字符（含标点数字）；用户要求摘要且实际保留时计入。两版用同一提取范围和方法。另报汉字数时明确为U+4E00—U+9FFF，不混用口径。
- 含表格、文本框、脚注或修订标记时识别其内容和修订接受状态，不以普通段落冒充全文。评价表、修改说明与正文分开统计；用户字数口径优先。
- 多个基准分别计算。对照上传修改稿达标，不代表对照早期稿也达标。禁止靠删署名、缩字号、压行距或减页数冒充文字压缩。
- 压缩不等于重新核验政策。新增或实质改变法律、统计、案例结论时查一手依据；保留的未核事实不称已验证，个人修订稿不当官方证据。
- 区分事实数字与拟议参数。抽测比例、试点数量、期限等无既定依据时标明建议；预警用于核验，参考标准与法定要求分别表达，采购限制和数据互认须有依据和程序。

## 5. 五项严格自评与修订

五项各按100分，等权平均。评分属编辑自评，不代表外部专家、独立事实核验或报送采用。用户要求逐项90分时，每项达到90才达标，不能只看平均数。

| 评分点 | 核查证据与扣分依据 |
| --- | --- |
| 原意与关键措施保留 | 原主张有去向；主题、主体、权利、例外和核心工具不被删失；实质变动明示 |
| 精简与信息密度 | 同口径比例达标；重复和无效铺垫删除；论证证据保留 |
| 结构与因果关系 | 首段事实先行、末句建议；问题为重点；三至四条对策编号清楚；按机制合并，无多主题塞段 |
| 制度可执行性与证据边界 | 谁做、怎么做、成本、权限、保障清楚；事实与拟议参数分开；重要待核未掩盖 |
| 语言与阅读节奏 | 通俗清楚，无残句、歧义、套话；小节段数及段长自然变化，长段有中心且可读 |

初审记录具体缺陷、定位和分数后再改稿；复审记录改动、剩余扣分理由及复评分。不得事后补造初评分或简单把89改为90。无先行记录的旧稿只标本次回溯评价，不称历史实测。

硬性不合格优先于评分：关键事实失实或未核且左右结论、核心主张丢失、明确压缩幅度或项数不达标、Word缺字截断，均不得用平均高分掩盖。可修则继续，确需用户材料或决定时说明具体缺口；不把不确定性伪装成解决。压缩目标损害原意时说明冲突与实际幅度。

## 6. 成品交付

正文、修改说明和自评分离，未经要求不把评分塞进提交稿。给出基准与完成数、缩短比例、问题及建议项数、主要变化、评分与剩余限制。Word检查最终全部页面，字体替代和版式调整如实披露。需要提交稿时交付独立可编辑Word；仅更新技能时不额外生成文稿。
