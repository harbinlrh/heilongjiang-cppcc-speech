# 内置产业园区提案范式

本范式提炼自用户指定的《关于做强产业园区集聚赋能高企发展的建议》。它保存可迁移的写法，不保存样稿中的事实结论。无需上传原文即可使用；不把原文署名、地区、项目、政策及调研经历带入新稿，也不声称逐字还原。

## 成稿的默认形态

准确题目、已确认署名、一段总述、四项行动建议。没有作者信息就不编署名。总述与建议连续推进，通常不另设摘要、背景、问题清单或结语。字数服从当次要求，不把样稿页数、字号和段落长度当作硬指标。用户要求独立问题章节、不同建议数量或资料附录时按要求调整。

题目采用《关于＋具体治理对象或制度动作＋的建议》，范围以一个可办理的核心问题为宜。避免把题目写成多个目标的堆叠。

总述完成四件事：说明政策对象的实际作用；用已核实的近期地方情况交代基础；点出相互区别的关键障碍；落到本稿拟解决的制度问题并引出建议。基础和障碍以证据为限，不能为了凑齐四类问题制造事实。没有可靠地方现状时，缩短开头，从可核实的制度要求与服务环节切入，不写虚构成效。概念有歧义时先用一句话说明口径。

## 四项建议怎样接续

样稿依次处理方向、资源、落实、效果。转入其他主题时保留这个思考顺序，再改成该主题真正需要的动作：

| 功能 | 要回答的办理问题 | 可迁移的标题写法 |
| --- | --- | --- |
| 确定对象和规则 | 谁需要解决什么，按何种口径分类，先做哪些事项 | 统一……口径，明确……范围 |
| 组织现有资源 | 谁提供服务，怎样匹配需求，如何减少重复投入 | 整合……服务，解决……衔接 |
| 落实到具体事项 | 谁受理、处理和反馈，跨部门障碍交给谁，怎样接续 | 细化……程序，推动……办理 |
| 检验实际效果 | 用什么口径判断成效，怎样纠错和调整，未完成事项如何继续 | 完善……评价，以……检验成效 |

这些是构思位置，不是每篇照抄的四个标题。标题要出现真实动作、办理对象和预期结果。原样稿的图、目录、任务单、评价表各有用途；新题没有实际需要，就不要为了像样稿而增加表单或系统。原则上用四项承载上述功能，确需三项或五项才能避免重复、保全机制时调整。不能把四种功能分别写成四段空话。

开头提出的障碍必须在建议中得到处理。已核实的案例与数据放在最能解释措施的地方，机构、时间、事实和来源简明交代，不把所有证据堆到总述。建议段侧重办理安排，不再重复大段意义和理论。

## 每项建议写到什么程度

用一至两个自然段展开一个主要制度工具。常见顺序是主管主体及对象、可用资源、具体办理过程、分类处理、执行边界、结果使用。按真实因果关系调整顺序，不要求每项字数相同或每段都以同一句型开头。

把抽象动词补足到可以办理：协调哪些单位、交付什么结果、谁承接下一步。可用“由……会同……”“依托现有……”“对符合……的……；对暂不具备……的……”“先……，再……”“将……作为……的依据”等句法，交替使用，避免连续同构。提到部门名称前核实现行职责；尚未确认时用职责称谓，不猜机构名称。

保留样稿中容易在润色时被删掉的制度约束：

- 利用现有机构、设施和业务记录，确需新建时说明需求、运营及持续成本，不以建平台代替提供服务。
- 按基础和阶段分类，弱基础对象先补现有服务，不能统一要求立即达到最高标准。
- 涉及企业、银行、专业机构的决定，保留自主选择和专业评审，不能把行政协调写成代替其决策。
- 跨地区或跨部门的事项交代分工、费用和后续承接，避免移交后无人继续办理。
- 评价看实际服务与对象变化；存量转移不冒充净增，投入数量不冒充服务成效，短期进度不替代长期结果。

只采用本题真正涉及的约束，不把这五条机械塞入每篇。

## 语言与节奏

语气务实、克制但有判断。少写抽象使命和排比口号，多写对象、动作、条件与结果。句子随意思长短交替，重要判断可短，复杂程序可用复句展开。自然连接前后动作，不给每句加首先、其次、此外。对话感来自清楚直接，不靠“对吧”等口头禅或故意破坏语法。

标题不必加引号，不强求同字数对仗。日期按当次要求写，通常用阿拉伯数字；引号、破折号和缩略语只在确有用途时使用。样稿中的宣传词不是风格的必要部分，用户禁词优先。末段停在具体的评价、服务接续或纠错安排，不补口号式总结。

以下为写法示例，仅表示拟议措施，不是已实施案例或已验证事实：

空泛句：加强部门协同，提升事项办理水平。

可用句：建议由主管部门明确跨部门事项的受理单位和转办条件，受理后向申请人告知承办单位；需补充材料的，一次说明理由和清单。转办不视为办结，由承办单位反馈办理结果。

空泛句：完善考核机制，推动工作取得实效。

可用句：建议将实际办结情况和服务对象反馈纳入评价，区分首次办理与重复反映事项。对未办结事项逐项说明原因，明确后续承办单位，不以转办数量代替解决数量。

## 无样稿时的交付前检查

检查总述是否有依据，四项是否各有职责且前后接续，标题是否指向真实动作，建议是否保留权限与执行条件。删除套话后再读一遍，确保自然但仍适合正式报送。不能用“符合样稿风格”掩盖事实缺口；不能为了模拟原稿而搬用产业园区术语。需要Word或邮件时，回到技能入口的交付流程。
