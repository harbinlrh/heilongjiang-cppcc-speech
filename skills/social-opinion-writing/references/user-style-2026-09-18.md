# 用户确认样稿的版式参考

本文件只承接2026年9月18日确认样稿的页面、字体和段落格式。公开版仅保留可独立使用的版式说明，不附私人样稿。2026年11月28日的新要求已替代历史样稿的篇幅、栏目、问题分析和语言规则；内容与结构以[结构与语言](writing.md)为准，署名信息和交付以[署名与交付](delivery.md)为准。不得从样稿恢复旧篇幅、两部分结构、只用短句或限制对话感的旧规则。

## 版式

| 对象 | 当前默认 |
| --- | --- |
| 标题 | 楷体22磅，不加粗，居中，单倍行距；允许自然逗号 |
| 题下反映人信息 | 楷体16磅，不加粗，居中，单倍行距；信息后空一正文行 |
| 一级标题 | 仿宋16磅，加粗，固定30磅行距，首行不缩进 |
| 二级标题 | 仿宋15磅，不加粗，固定30磅行距，首行缩进2字符 |
| 正文 | 仿宋15磅，不加粗，固定30磅行距，首行32磅，两端对齐 |
| 页面 | Letter，21.59×27.94厘米，上下2.40厘米、左右2.60厘米 |
| 其他 | 段前段后0磅，无页眉、页码、横线或装饰边框 |

正文及各级标题颜色262626，主标题与题下信息为黑色。中文、西文字体按段落角色分别显式设置ascii、hAnsi、eastAsia，清除不相干的主题字体，不恢复旧Times New Roman默认。字体必须在渲染环境实际可用；替代时报告真实情况，不仅检查DOCX内的字体名称。

标题与后文保持同页。题目若只剩一个字单独换行，优先在自然停顿处平衡断行，不以缩小字体压页。样稿二级标题的缩进曾有2字符与1.5字符差异，新稿统一2字符；不复制原件末尾空段等编辑残留。

## 使用边界

样稿的标题、事实、日期、署名和问题项数不能直接套入新稿。原样稿事实即使出现较早资料，也不免除新稿的证据时间规则。篇幅按当前正文约2500字、整篇不超过3000字的要求执行，不固定页数，不为压页改字号。

当前用户新模板、明确要求及有效征集通知优先。此样稿只作版式依据，不证明个人身份、数据事实或政策现行效力。公开版本仅保留通用版式，不附私人DOCX。生成Word后仍须实际渲染、逐页检查并回读文本。
