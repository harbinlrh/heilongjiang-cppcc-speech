# 层级、中心任务与选题

## 参政议政主线如何进入选题

围绕学习贯彻中共二十大及后续重大会议精神、全面贯彻实施十五五规划部署和推动经济社会高质量发展，把前沿一线的真实情况转化为能供党和政府决策、施策参考的具体问题。上述内容是选题和政策判断的方向，不要求每篇开头复述全部会议、规划和口号。

借鉴民建中央拆解中央经济工作会议文件的工作方法，地方选题应拆解当地党委、政府年度重点目标，寻找民建能够发挥经济领域联系广泛、专业观察等特色优势的具体切入点。不能仅因题目出现经济、产业等词就认定具有特色，也不能把部门年度任务改写一遍充当社情民意。

执行时先核验成稿时最新的有关会议文件、规划部署和本级年度任务；区分已公布部署、征求意见内容与作者建议。不把本技能中的政策背景说明当成某项任务已实施的证据，不复制用户材料中没有对应原文的编号引用。

## 年度重点任务拆解工作表

先在内部形成下表，再决定写哪一个问题。没有依据的格子如实留空或注明待核，不为填满表格编造任务、调研或职责。该表是选题工作记录，默认不附在正式成稿中。

| 需核验的内容 | 需要形成的具体判断 |
| --- | --- |
| 中央或地方部署的文件、发布日和原文定位 | 当前要求解决什么实际事项，适用什么范围 |
| 本级年度目标与对应任务 | 哪项结果、服务或规则需要改善，是否已有明确安排 |
| 一线对象与办理环节 | 哪类企业、群众或机构在什么具体环节遇到问题 |
| 数据或案例及支持范围 | 哪项合格证据能够说明障碍，哪些结论尚不能成立 |
| 机制原因与现有制度 | 规则、标准、程序、激励或责任如何影响结果，是否存在替代解释 |
| 权限和政府、市场、社会边界 | 谁依法负责，谁可以自主决定，哪里需要上级授权或社会参与 |
| 民建可提供的观察和专业贡献 | 已有何种真实行业联系、调研资料或专业分析，能补足什么决策信息 |
| 拟解决的一个核心问题 | 可以用一句具体的话说明哪个环节应当怎样改变 |

工作程序为核对部署、拆解任务、查找一线问题、核验证据、审查权限、形成选题、检查建议是否回应问题。新发布任务或证据改变判断时，修正选题依据；不为保留原题忽略已解决事项。把围绕中心、服务大局落实到这些判断和记录，避免只在开头表态。

## 按政策对象和执行权限选口径

| 口径 | 必须回答 | 证据与权限边界 |
| --- | --- | --- |
| 全国 | 地方案例揭示什么共性制度问题，为什么需要国家层面调整 | 地方个案能证明风险存在，不直接证明全国普遍发生；以核实的全国规则、统计或其他适当证据说明共性机制。国家建议与地方实施分别表述 |
| 黑龙江 | 与本省有什么具体联系，为什么需要省级解决 | 核查跨市地衔接、共同规则或省级资源统筹等必要性；哈尔滨案例不代表全省。全省统计、地方样本和外省参考分开，市县差异影响实施方案 |
| 哈尔滨 | 哪个市级服务、流程或治理障碍需要改变 | 以本市事实和职责为依据，区别市级、区县及街道社区职责；省级、中央或垂直管理事项提出协调、报请或授权建议，不写成市级可自行决定 |

- 作者工作地、样稿署名、材料出现的地名都不能单独决定报送层级。受众是省级领导也不等于一切问题都在省级权限内。
- 已明确层级但材料支撑不足时，先补查共性机制；仍不足则保留个案范围，提出有依据的风险提示或缩小议题。确需改为另一层级才说明理由并征求选择，不擅自改题。
- 使用寒地、城乡距离、农业、边境、人口或产业特征，必须与所论问题存在有依据的联系，不为体现地方特色堆标签。
- 当前机构全称、职能、政策效力和上下级权限通过权威来源核实；本文件不是具体部门职责清单。
- 从国家治理的制度需要观察地方问题，仍须遵守实际报送层级的权限。不能把宏观视角等同于一律要求中央发文，也不能把地方材料写成工作汇报或成绩表扬。

## 政府、市场与社会的边界

先说明问题为何需要公共治理介入，再确定工具。政府责任应有法律职责、公共利益、公共服务或市场运行中的具体障碍作为依据，不能只因某个主体有成本就要求财政承担。

| 主体 | 应具体判断的职责或作用 | 需要避免的扩大解释 |
| --- | --- | --- |
| 政府 | 依法制定和执行规则，提供必要公共服务，维护公平竞争，保障权利，开展法定监管并处理职责内争议 | 代替企业决定一般经营、技术和定价事项，未经测算普遍补贴，以新机构或新平台替代问题分析 |
| 市场主体 | 在法定和合同边界内自主经营、议价、选择技术、承担相应成本和风险 | 将所有成本转嫁公共财政，或以经营自主为由规避法定义务和合同责任 |
| 社会组织及专业机构 | 在实际能力和合法授权范围内提供专业服务、行业协商、自律、第三方评价或纠纷调解 | 凭建议取得行政强制权，未经核查承担法定审批职责，增加强制收费或重复认证 |

逐项核查政府该管什么、不该代替谁作决定，市场能否通过合同、竞争和合理价格解决，社会力量能否提供必要补充。边界依据具体法律和事实判断，不能机械使用政府退、市场进等口号。涉及现行政府定价、公益服务或其他特别规定时先核实适用规则，不套用一般市场议价假设。

建议优先检查现有制度、流程和资源能否调整。新增财政投入、机构、平台、审批或强制标准时，写清拟负责部门、工具、动作、适用对象及承担者，核查必要条件和替代办法；涉及上级权限时明确报请、协调或试点授权程序。不能把无据的固定时限、额度和比例写成现行要求。

## 聚焦与去重

一篇只解决一个核心问题，优先具体制度、办事手续、费用责任、服务环节或执行障碍。相邻领域只有直接解释该问题时纳入。一个案例足以支撑的论点不再堆同类案例。

有可用历史材料时，按政策对象、核心问题、主要制度工具、管辖层级比较，而非仅比标题。保留旧稿的来源与版本，识别延续、新证据和实质新增措施。历史材料可以帮助检索和去重，其旧事实能否进入正文仍须经过 [证据与问题审查](evidence.md) 的时间条件检查。无权访问的数据库不绕过权限；不能访问去重清单时仅说明检查范围，不宣称题目独创。除非用户另行要求，不新增远端登记。

同题多个层级必须分别选择事实范围、调整对象和责任分工。共同语言标准可复用，统计、权限、预算和执行程序不可直接平移。
