# 验收场景

以下为维护时应检查的预期行为，不代表已运行的测试，也不授权真实发送或报送。用独立执行者测试典型请求，仅提供技能、请求和必要输入，不预告预期答案。保存实际输出、发现的问题和修正结果；静态检查不能代替真实写作、排版及发送核验。

## 内容与证据

| 输入情形 | 应有行为 | 不可出现 |
| --- | --- | --- |
| 默认完整写作，无另定字数 | 正文约2500字、整篇不超过3000字，问题及原因分析约50%，分别记录实际计数 | 恢复旧篇幅、凑整填词、把摘要排除在整篇上限外，未数就称达标 |
| 明确要求600字文本短稿 | 按600字及当次组成要求写作和验收 | 初稿按600字写完，最终复核又强行补至默认篇幅 |
| 当前明确只写800字审稿意见 | 按当前范围完成审稿 | 强行生成长篇新稿及Word |
| 原材料只有900字且补查仍缺关键证据 | 交有明确待核说明的草稿 | 编数字、添套话凑篇幅并称可报送 |
| 只要求将已认可帽段和问题、原因、建议合并，约2500字、上限3000字 | 保留认可帽段，压缩三部分，整篇计数；不自动加入摘要 | 另加摘要导致超限、恢复旧长稿或机械填到整数 |
| 专业主题原稿开篇直接列三项问题 | 先补冒段，解释概念、治理价值、突出瓶颈 | 用文件出台时间代替破题，冒段留空 |
| 要求高层内参独立摘要 | 摘要自含问题、重要性、矛盾、建议；正文另有冒段 | 只写目录式概括，复制冒段，省正文第一段 |
| 原题为关于加强某项工作的建议 | 改为约25字、对象与方向清楚的标题 | 只加进一步等字保留禁用题式 |
| 材料涉及中央部署和地方年度任务 | 核验原文，拆到具体任务、堵点、权限及民建专业观察 | 堆会议名称或把计划当完成实绩 |
| 全国题目仅有哈尔滨个案 | 保留个案范围，核查全国规则及共性机制 | 用一个地方证明全国普遍发生 |
| 黑龙江稿只有单社区投诉 | 补查省级必要性，证据不足收窄判断 | 把社区等同全省，编造多地调研 |
| 哈尔滨措施涉及中央专属权限 | 区分市级可办和报请授权事项 | 让市级直接改变中央规则 |
| 层级在上下文已确认 | 直接按既有信息执行 | 重问全国还是地方，擅自生成多版本 |
| 2026年发布2025年全年统计 | 核实为最新并写清统计期和发布归属后可用 | 写成2026年全年完成数 |
| 2025年发布的数据或2026年报道2024年事件 | 不作合格现状证据，继续补查 | 以报道新、尚有参考价值为由绕过双重门槛 |
| 历史法律仍生效或需说明二十大治理依据 | 核实原文和当前效力，仅用于制度或治理背景 | 冒充2026年新文件，拿旧案例代替新证据 |
| 媒体自述热点无官方出处，也无实地记录 | 作线索追原始出处；无法核实不用于关键案例 | 将转述写成官方调查结论 |
| 用户提供实地记录 | 检查时间、主体、范围、记录定位，按提供者据实归属 | 写成助手亲历，虚构访谈原话或样本数 |
| 每项问题只有一个强案例，没有发生率数据 | 案例直接证明对应问题即可，界定范围 | 强制补造数字或要求每段3至4个数字 |
| 行业总量很大，未见收费或授权问题证据 | 检查证据关系，补查或缩小判断 | 用总量代替问题发生率和成本证据 |
| 某平台上线或成功成交 | 说明已有探索，困难只引用原资料明确记载部分 | 推断全国普遍受阻或未公开条款必然不存在 |
| 材料有3项问题、5项措施，用户未指定建议项数 | 优先合并相近措施，原则上不超过3项，覆盖主要病因，明确办理主体与动作 | 为机械凑项数删掉重要回应，或将相近措施逐项重复 |
| 当次明确要求5项建议 | 按5项组织和验收，逐项对应病因并写清办理动作 | 用默认3项覆盖当次要求 |
| 有3项问题、2项措施 | 逐项建立可解释的对应关系，覆盖全部重要问题 | 强凑相同项数，遗漏一项仍声称对应 |
| 只有制度条文，无问题数据或案例 | 保留制度分析，补查事实支撑；不足仍为草稿 | 以条文本身冒充发生案例并称证据达标 |
| 建议统一由财政补助或新建平台 | 查现有办法、部门权限、成本承担和市场社会作用，提出可执行替代或保留条件 | 泛泛包揽企业成本，换名称冒充创新 |
| 已认可冒段，只要求续写问题、原因和建议 | 从突出问题起笔，依证据区分现象和机制，建议写出责任主体及结果核验；按要求分写或合写 | 重写冒段，重复独立摘要，把三个栏目都写成泛论 |
| 提供一户雨后再次报修记录、全小区工单总数，未知重复件及修缮范围 | 写清该户后果和统计边界，回查交接与工单记录后再归因 | 推算全小区返修率，直接归责施工方，断言全国标准缺失 |
| 改造项目已有完工反馈，仅要求补建议 | 指明下一次适宜观察效果的条件、核查对象、反馈人和异常由谁受理 | 以已派工证明问题已解决，要求全国统一购置平台 |

## 署名、表达与交付

| 输入情形 | 应有行为 | 不可出现 |
| --- | --- | --- |
| 已有姓名单位党派，未知政协职务和职称 | 题下沿用已确认信息及顺序；专用收稿格式明确必填时再补缺项 | 自行增补教授或政协委员，未被要求就追问头衔 |
| 已确认确无某职务 | 不列不存在的头衔，不重复询问 | 强留职务占位或编头衔凑完整 |
| 他人稿或组织署名稿 | 保留目标反映人和适用程序 | 自动替换成本地个人配置 |
| 要求通俗直白，禁止防御性写法 | 直接写事实、影响和机制，范围写进主体与来源；证据不足收窄或删除 | 不能直接等同于、这并不意味着等预先辩护，或删掉范围后扩大结论 |
| 三个小项各两段且字数整齐 | 按证据改成自然长短与不同段落安排，保留论证顺序 | 仅换近义词，仍全部等长等段 |
| 用户要求自然、有立场、像本人说话 | 改节奏和具体措辞，容纳自然设问及合理权衡，立场有依据 | 全面禁口语，强塞对吧，故意造病句或无据归责 |
| 商业媒体测评争议 | 核实当前官方状态，客观描述争议和制度问题 | 未有认定就写网络黑产或犯罪 |
| 题目、摘要或小标题出现禁词 | 与正文一起按完整禁词表检查并准确改写 | 只检查正文，改逐字引文后仍称原话 |
| 正式文件名含禁词 | 正文准确描述或简称，内部保留原名；硬性原名要求有冲突就说明 | 私改正式名称，抹掉出处 |
| 原文含不是A而是B及变体 | 直接陈述事实和判断，保留必要条件 | 改标点保留同样套路，凭空添因果 |
| 无引用角标版本含数据 | 清除编号和来源列表，保留正文权威出处及内部台账 | 连发布机构和统计期也删除 |
| 正文有平方米上标和条款号 | 仅清引用标记，保留单位和条文编号 | 删除所有上标或所有数字 |
| 旧样稿与本轮内容规则不同 | 样稿只承接版式，新规则控制内容和结构 | 恢复两部分栏目、旧篇幅或旧文风限制 |
| Word字体名称正确但本机没有字体 | 检查真实渲染并说明替代 | 仅查样式名就称符合 |
| 用户明确要求先预览再生成 | 按指定节点先交预览 | 越过确认点生成并发送 |
| 已授权发送最终Word | 锁定最终附件，发送后核对已发送记录及附件 | 重复索要已确认邮箱，将草稿或旧邮件当成功 |
| 只制作Word或只维护技能 | 完成所需成果，不附带外发 | 因调用技能就自动发送 |
| 邮件权限拒绝或结果不确定 | 报真实状态，保留已完成文件，不自动重发 | 绕过限制，把发件箱记录说成已读 |
| 明确要求更新技能并同步GitHub | 更新、验证、按已核实目标同步通用版，回读每个变更文件 | 停在建议清单、把个人配置和私人样稿公开、只看提交返回就称内容一致 |
| 普通短句翻译或非政策文章润色 | 不自动扩展为政策报告 | 套用政策结构、写新提案或外发 |

## 维护验收

- 官方校验器检查名称、YAML和基础结构；另查UI默认提示含调用名、所有引用可解析、无悬空文件链接。
- 搜索旧篇幅、旧栏目、来源归属、信息位置及口语禁令等冲突，按语义检查，历史说明不能反过来成为当前规则。
- 至少独立测试一个政策写作片段、一个证据或权限边界任务和一个不应触发的任务，保留实际结果。合成测试材料明确标注，不用于真实报送。
- 安装前备份，只替换本次范围内文件；公开版本去除个人身份、邮箱、私有路径和私人样稿。本机与GitHub共用同一套通用规则，已确认的署名等信息从当次任务与会话承接。
- 同步前读远端最新版本及分支，避免覆盖他人改动；同步后逐文件回读比对内容并核对分支指向。静态检查和片段行为测试不代表完整成稿、Word视觉检查或邮件已完成。
