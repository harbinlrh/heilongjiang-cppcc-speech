# 层级与交付

## 只读取并应用对应层级

| 层级 | 问题论证 | 建议权限 |
| --- | --- | --- |
| 全国 | 解释全国制度或跨地区共性机制；地方案例限定支持范围，全国普遍性判断需相应证据 | 中央主管部门、全国规则与地方实施衔接；区分立法、行政管理和地方执行 |
| 黑龙江 | 说明跨市地协调、共同规则或省级资源统筹的必要性；哈尔滨个案不能代表全省 | 省级确定什么、市地县执行什么；国家专属或跨省事项写报请、协调或授权申请 |
| 哈尔滨 | 用本地事实说明市级治理障碍；寒地、人口和产业条件仅在与问题有关且有证据时使用 | 市级可办理环节及区县实施责任；省级、中央或垂直管理事项说明协调程序 |

同题多层级分别核验事实、重写问题和措施，不仅替换地名。拟议分工与法定职责分别表达，核实当前机构与权限。

## 承接已有个人规范

本技能综合 national-social-opinion-word、heilongjiang-policy-proposal、harbin-policy-proposal、policy-proposal-editor、social-opinion-writing 的方法，不修改它们。

署名、命名和版式依次采用当次要求、已确认原稿或模板、已确认的同层级个人规范。需要恢复该信息且原技能可用时，只读取相应个人规范：全国用 national-social-opinion-word 的 personal-model-profile；黑龙江用 heilongjiang-policy-proposal 的 personal-document-profile；哈尔滨用 harbin-policy-proposal 的 personal-document-profile。用户明确单署名、双署名或指定其他版本时从其要求，不擅自统一不同署名配置。

原技能不可用不妨碍写作：保留原稿署名和有效模板；确实缺少必需身份信息时单独说明或询问，不编造。本公开技能不内嵌个人身份、邮箱或本机路径。原技能中的旧条数、开篇和篇幅分配规则不覆盖本技能。

无有效模板时，以A4、清楚的中文字体和层级、适宜行距、首行缩进与连续页码制作可读文档，不声称复刻旧样稿。文件名保持完整题意，月份按当次要求或稿件日期，没有指定再用当前月份；仅在已确认的命名规则需要时加组织前缀。

## Word 与外部交付

- 完整成稿默认用当前可用文档工具或技能生成独立可编辑 DOCX；来源记录单独留在内部工作区。原稿不覆盖。
- 检查最终正文内容、标题、署名、编号、文件名和元数据，渲染全部页面，逐页看缺字、断行、截断、异常空白和孤立标题。修改后核验最终版本；不能把结构检查冒称视觉检查。
- 只写文字、讨论、选题、审稿、预览或维护技能时按请求交付，不强制生成文件。
- 当前明确要求发送或提交时，使用已确认的目标和授权完成操作及独立回读；仅调用技能不代表发送。邮件核验匹配的已发送记录和附件，已发送不等于收件人收到或阅读。不明状态不自动重发。
- 技能同步 GitHub 需当前授权，核对账号、仓库、分支、路径、可见性和适用提交规则，只上传指定范围，并回读每个文件。历史成功不代替当前验证。
