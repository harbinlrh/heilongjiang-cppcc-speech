# 指定样稿的 Word 版式记录

仅在用户要求 Word、严格复现版式或指定本稿为排版模板时读取。本记录来自原 DOCX 的 OOXML 结构测量，没有对原件进行页面渲染验收；页面数和实际字体呈现不得据此断言。

| 项目 | 文件中的设置 |
| --- | --- |
| 纸张 | 12240 × 15840 twip，即 US Letter，约 21.59 × 27.94 cm；不是 A4 |
| 页边距 | 上下 1361 twip，约 2.401 cm；左右 1474 twip，约 2.600 cm |
| 标题 | 方正小标宋简体，22 pt，居中 |
| 摘要和正文 | 仿宋_GB2312，16 pt |
| 问题领起句 | 楷体，16 pt |
| 建议领起句 | 黑体，16 pt |
| 正文段落 | 两端对齐，固定行距 30 pt，首行缩进 30 pt，段前后 0 |
| 结构 | 标题之后是含反映者信息的摘要；概念段再次出现反映者信息；没有独立署名行；无表格 |

版式依据优先级为：用户本次明确要求 → 本次正式表单或单位模板 → 用户要求复现的样稿。只有明确复现本稿版式时，才保留它的 Letter 设置；一般提案 Word 未指定模板时可选 A4，但应说明这是新文件的编辑选择，不声称严格复制了原件。

使用当前可用的文档制作工具完成独立 DOCX，保留输入。要求使用本稿字体而环境中缺字库时，用可用字体替代并说明，不把 XML 中写有字体名等同于正确渲染。

命名以当次要求为准；未指定时可用“关于〔具体事项〕的提案.docx”。不要复制原始文件序号“12”，也不自动添加“南岗一”、旧年月或其他样稿标记。

最终版本核对正文、段落、编号、字体设置与实际文字；渲染后逐页检查缺字、溢出、标题与下文分离等问题。实际渲染未完成时，明确仅通过结构检查。
